## Workflow

1. Each iteration has its own directory: `docs/iterations/iter-N/`
2. Each iteration contains:
   - `prd.md` — Product Requirements Document (goals, features, scope)
   - `tasks.md` — Task breakdown with status tracking
3. Use `/iterflow new` to create a new iteration
4. Use `/iterflow` to resume work on the current iteration
5. Use `/iterflow status` to check progress
